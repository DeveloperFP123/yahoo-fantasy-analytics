# Personal Yahoo Fantasy Football Analytics

This is a private-use, non-commercial project for analyzing my own Yahoo Fantasy Football leagues using read-only Yahoo Fantasy Sports API access.

The project is intended to retrieve and analyze:

- League settings
- Teams and managers
- Standings
- Rosters
- Weekly matchups
- Draft results
- Transactions
- Waiver activity
- FAAB bid information where available
- Historical league and season data

The data is used for personal fantasy football analysis, including roster management, waiver-wire decisions, FAAB recommendations, lineup decisions, and historical league analysis.

This project is not a commercial service and is not offered to the public. API usage is expected to be low-volume and limited to leagues associated with my own Yahoo account.
